# Hospital São Lucas do Vale

## E-mail recebido em 21/09/2026
**De:** Juliana Castro — Gerente de TI, Hospital São Lucas do Vale
**Assunto:** Proposta — desktops virtuais

Prezados,

Temos cerca de 1.100 estações de trabalho entre recepção, enfermagem, farmácia e administrativo. Hoje usamos desktops físicos com Windows 10, que perdeu suporte. Queremos migrar para desktops virtuais com Citrix, com acesso ao prontuário eletrônico a partir de qualquer estação, inclusive thin clients.

Nossa preocupação principal é a disponibilidade 24x7, porque o hospital não para, e a conformidade com a LGPD para dados de saúde.

Gostaríamos de uma proposta técnica de assessment e desenho da solução, com estimativa para a implantação.

Atenciosamente,
Juliana Castro
